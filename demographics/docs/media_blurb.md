A comprehensive demographic dataset combining age, gender, and race/ethnicity distributions from the American Community Survey across a 16-year time series (2009–2024), standardized to 2020 Census geographies using area-weighted crosswalks that redistribute pre-2020 values across boundary changes. Raw ACS estimates shift with each decennial redistricting, making direct year-over-year comparison impossible — this dataset solves that problem by placing all years on consistent block group, tract, and county boundaries with margins of error preserved. The resulting 27 measures are immediately interoperable with each other and with the broader Social Data Commons collection, enabling researchers and policymakers to analyze how demographic composition intersects with economic opportunity, health access, housing affordability, and infrastructure across communities.
