# Abstract: Rubric and Instructions

## Purpose
The abstract is a standalone summary of the data paper. It must be comprehensible without reading the full article and cannot contain citations, equations, or URLs.

## Requirements (Data & Policy)
- Maximum **250 words**
- No citations, references, or URLs
- No sub-headings
- Must stand alone: a reader should understand what the dataset is, how it was made, and where to get it
- No scientific claims or hypothesis testing
- Plain text only (no formatting, no abbreviations without definition)

## Structural Template (4 sentences)

1. **What this paper does** (1 sentence): "This data paper documents a dataset of [N measures] of [topic] for [geographic scope] at the [resolution] level for [time period]."
2. **What the measures are** (1-2 sentences): List the measures by name and type.
3. **How it was made** (2-3 sentences): Name the primary data sources and core methodology.
4. **Scale and availability** (1 sentence): State the number of geographic units, where the data is deposited, and that it is freely available.

## Quality Checklist
- [ ] 250 words or fewer
- [ ] No citations or URLs
- [ ] No sub-headings
- [ ] Describes what, how, and where
- [ ] No scientific claims
- [ ] All abbreviations defined at first use
- [ ] Can be understood without reading the paper

## Execution Steps
1. Read pipeline.yaml and measure_info.json to get dataset scope.
2. Draft following the 4-sentence template.
3. Count words. If over 250, cut adjectives and compress.
4. Verify no citations or URLs leaked in.
