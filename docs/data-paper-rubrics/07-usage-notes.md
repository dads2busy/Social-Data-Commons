# Usage Notes: Rubric and Instructions

## Purpose
Practical guidance for users of the dataset. Helps researchers who have downloaded the data understand how to work with it, what to watch out for, and what the data is and is not suitable for.

It does NOT serve as a conclusions section, contain selling points, or repeat Methods/Technical Validation content.

## Structural Template (300-800 words)

### File Access and Software (50-100 words)
- How to download
- Software for opening file formats
- Decompression steps if needed

### Interpreting the Measures (100-200 words)
- What high/low values mean
- Reference thresholds from literature (if any)
- Expected value ranges

### Scope Limitations (50-150 words)
- Most important exclusions affecting interpretation
- Geographic coverage and boundaries

### Temporal Comparability (50-150 words, if multi-year)
- Different source vintages between years
- Methodology or definitional changes
- How to isolate supply vs. demand changes

### Current Policy Use (50-100 words, if applicable)
- Name specific dashboards or agencies using the data
- State as fact, not promotion

### Appropriate and Inappropriate Uses (50-150 words)
- 2-3 appropriate use cases
- 2-3 uses the data is NOT suitable for

## Quality Checklist
- [ ] Software recommendations stated
- [ ] Interpretation guidance provided
- [ ] Scope limitations restated
- [ ] Temporal caveats noted (if multi-year)
- [ ] Appropriate and inappropriate uses named
- [ ] Not a conclusions section
- [ ] 300-800 words

## Execution Steps
1. Read output files for formats and compression.
2. Read measure_info.json for variable descriptions.
3. Read Technical Validation Known Limitations for caveats.
4. Research interpretation thresholds in the literature.
5. Draft following template.
