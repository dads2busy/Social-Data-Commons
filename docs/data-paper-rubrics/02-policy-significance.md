# Policy Significance Statement: Rubric and Instructions

## Purpose
A Data & Policy-specific requirement. Summarizes the significance of the dataset for policymakers, written at a level understandable by a broad audience. Appears directly below the abstract in a styled box.

## Requirements
- Maximum **120 words**
- Written for policymakers, not researchers
- No jargon, no abbreviations, no citations
- Must answer: "Why should a government agency care about this dataset?"

## Structural Template (3 sentences)

1. **The policy gap** (1 sentence): What information do policymakers currently lack?
2. **What this dataset provides** (1-2 sentences): What can agencies do with this data that they could not do before? Name 2-3 specific actions (e.g., target subsidies, identify underserved areas, track changes over time).
3. **Current use** (1 sentence, optional): If the data is already in use in a dashboard or by an agency, state this as a fact.

## Quality Checklist
- [ ] 120 words or fewer
- [ ] No jargon or technical terms
- [ ] No citations
- [ ] Names specific policy actions enabled by the data
- [ ] Written for a non-technical reader

## LaTeX Format
```latex
\begin{policy}
[Statement text here]
\end{policy}
```

## Execution Steps
1. Identify the policy domain (health, education, housing, environment, etc.).
2. Identify 2-3 specific policy decisions the data supports.
3. Draft following the 3-sentence template.
4. Count words. If over 120, cut to the most actionable claims.
5. Read aloud: would a state legislator understand this? If not, simplify.
