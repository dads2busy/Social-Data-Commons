Fixed and mobile broadband speed measures derived from millions of Ookla Speedtest results, spatially joined from global hexagonal tiles to 2020 Census block groups using geometric intersection and aggregated with device-count weighting to produce annual estimates at block group, tract, and county levels. This spatial transformation converts raw crowdsourced speed test data — which has no inherent Census geography — into standardized measures that can be directly linked to demographic, economic, and health datasets for policy analysis. As broadband access becomes essential for telehealth, remote work, and education, this dataset enables policymakers to pinpoint neighborhoods where inadequate internet infrastructure perpetuates digital divides and limits economic participation.
